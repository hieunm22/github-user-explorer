================================================================================
                              API ENDPOINTS
================================================================================

GitHub REST API Calls:

1. Search Users
   GET https://api.github.com/search/users
   Params: q, page, per_page, sort, order
   Used in: SearchPage, searchSlice

2. Get User Details
   GET https://api.github.com/users/{username}
   Used in: UserDetailPage, userDetailSlice

3. Get User Repositories
   GET https://api.github.com/users/{username}/repos
   Params: page, per_page, sort, order
   Used in: UserDetailPage, userDetailSlice

4. Get User Followers
   GET https://api.github.com/users/{username}/followers
   Params: page, per_page
   Used in: UserDetailPage, userDetailSlice

5. Get User Following
   GET https://api.github.com/users/{username}/following
   Params: page, per_page
   Used in: UserDetailPage, userDetailSlice

├── URL Params: username (from route)
└── Features: Profile, Repos, Followers, Following
